# v17.14 release verification

Date: 2026-10-13. Release: v17.14. Prepared from the v17.13 tree at commit `f7f4218`.

## Why

v17.13 replaced the Pro slot with Argon but left every Auto-profile row on Flash. The user, on a paid key, asked which model suits each row. The recommendation was to put three rows on Argon: those where deeper reasoning pays off and the output stays well inside Argon's 32,768-token ceiling. The user then asked for those three to become the shipped defaults.

## Change

- **`TOOL_PROFILE_DEFAULTS`:**
  - `priority:{m:'argon',lv:'medium'}`: the R1–R9 cascade. Argon parts are 20,000 characters. Medium rather than high because the v17.7 run spent 62,914 tokens thinking in one request.
  - `cases:{m:'argon',lv:'high'}`: one request per case, output bounded at 5 stages × 4 questions.
  - `itemAudit:{m:'argon',lv:'high'}`: one rendered item per call. The v15.7 comment keeps its history (Flash was a free-tier cost decision) and records why it no longer applies. The only measured audit configuration (2026-08-20) was 3.1 Pro/high.
- **Unchanged:** the other seven rows, `forTool`, the profile loader (saved rows still win), Reset to recommended, the transport and every prompt.

## Verification

- `node verify-repo.js`: all gates pass.
  - 3,595 assertions (2 new).
  - All eleven frozen prompt hashes unchanged.
  - `Prompts.md` regenerated for the new filename only.
  - LF and version checks pass, and the full JSX Babel transform succeeds.
- **New assertions** (`tools/settings-persistence-tests.js`):
  - the exact shipped table: Argon for the three rows at the stated levels, Flash and the old levels everywhere else;
  - saved Flash rows for those three tools still load as Flash.
- **Updated assertions:**
  - `latte-tests.js`: the itemAudit default and the comment that documents it.
  - `tools/anki-review-quality-tests.js`: the "every other tool default" table.
  - `tools/remediation-tooling-tests.js`: NEIA `--app-profile` resolves to the shipped Argon model at high and Davis to Flash at low. A rewritten Flash itemAudit row still resolves to Flash.
  - The v17.13 Pro-migration test now uses `nclexgen`, which still defaults to Flash, so it cannot pass by falling back to the default.
  - Version assertions now read 17.14.
- **Browser.** The built-in browser pane loaded a scratch copy, served by a local static server, with no API key.
  - A full v17.13 profile table (all Flash) survived a reload unchanged.
  - **Reset to recommended** produced exactly the new table, in the UI and in storage: Priority · synthesis Argon · medium, Case studies Argon · high, Item quality · audit Argon · high, the other seven unchanged.
  - With the Cases tab open, the drawer's "what the open tab will use" badge read `gemini-4-argon high` with the Argon dot.
- **SRI.** All eight SRI-pinned scripts and both PDF worker copies were re-hashed on 2026-10-13 and match.
