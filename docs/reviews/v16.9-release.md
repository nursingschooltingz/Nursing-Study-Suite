## Scope

Twelve defects, 17 exact-match edits, each proven unique before replacement and each carrying a
`v16.9:` comment explaining why the previous behavior was wrong. Eleven of the twelve are defects
older than v16.8; one is in code v16.8 itself changed. Two first-attempt fixes were withdrawn after
counterexamples and rebuilt — both are documented in the follow-up record.

Unchanged: the eleven frozen prompts and `prompt-baseline.json`, model profiles and defaults, token
ceilings, warning tiers (none promoted), dependency and CDN/SRI pins, the single-file no-build
architecture, and every existing study export format apart from the Anki quoting noted below.

## Compatibility

- Anki export bytes change only for a note whose field contains a `"` or begins with `#`. Such a
  field is now quoted with doubled inner quotes so it survives import instead of losing the quote or
  merging the notes that follow. Every other note exports byte-identically.
- A blank calculation answer and a malformed card transcript section are now refused. Both close an
  incorrect acceptance: the first printed `Answer: —` as though the item were complete, the second
  crashed or corrupted the extracted source text.
- Historical generated artifacts are not retroactively repaired.

## Limits

- No live Gemini call, private course material, real PDF/PPTX corpus, mounted-browser acceptance or
  native Anki import was part of this release. Actual-PDF prevalence for the Fahrenheit collision,
  the split-mode boundary defect and scalar condition metadata remains unmeasured.
- Split-mode boundary recovery needs at least two explicit question headings and still cannot
  separate one question from a genuine numbered list beneath it.
- Worksheet option recovery handles indented continuation lines only.
- The 28 comments added in v16.8 that are labelled `v16.7:` are deliberately left alone; relabelling
  them is a mechanical change with no behavior, and several test extraction anchors quote comment
  text.
