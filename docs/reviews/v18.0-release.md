# v18.0 release verification

Date: 2026-10-13. Release: v18.0 (prepared as v17.16). Prepared from the published v17.15 tree at commit `a457355`.

## Why

Steps 6–10 of the [v17.14 production review](production-review-2026-10-13.md) plan.
- **Step 6** covers false failures and lost Priority text. A worksheet batch that fails validation skips its item audit, so a false failure costs the audit as well.
- **Step 7** covers content the NCLEX to Anki converter and the plain-text exports dropped or misread.
- **Step 8** strengthens the gates and adds missing tests; it does not change the application.
- **Step 9** removes start-up, typing and degenerate-input costs without changing results.
- **Step 10** fixes the remaining Low findings.
  - Six area groups were each reproduced and patched against the same snapshot.
  - Each patch is a set of exact-once replacements, applied in turn with the harness run after each.
  - The CHANGELOG lists each finding.

## Change

- **M9 — "Why X is incorrect".** `ngParseKeyItem` accepts it and normalizes the kind to "wrong". `ngLetterNumberedOptions` (three regexes) and the shuffle's `WHY` accept it too.
- **L31 — Oxford-comma keys.** The answer separator `(?:[ \t]*(?:,|;|\/|&|\band\b)[ \t]*|[ \t]+)` becomes `(?:[ \t]*(?:,[ \t]*(?:and\b|&)?|;|\/|&|\band\b)[ \t]*|[ \t]+)` in all three copies.
- **M4 — clock times.**
  - `scanUncitedProse` removes "hours/hrs" after a 24-hour clock time before matching.
  - `caseBuildPrompt`'s narrative rule lists time spans and cm/mm/kg/lb, and asks for elapsed time in words or in data. Prompts.md was updated with it.
- **M5 — fractions and intervals.**
  - In `caseAuditTextValues`, an unsupported plain fraction passes when a cited fact states the same fraction, or (instantiated only) when the value is N/10 with N ≤ 10 and a cited fact gives a 0–10 scale. A sentence-ending period does not count as part of the number.
  - `caseNumericTokens` rewrites qNh / qN min as "every N hours/minutes" before scanning.
- **M6 — thousands separators.** `caseCalculationEvidence` operands and the bare-answer check accept thousands separators.
- **M21 — Priority retries.** Each synthesis part keeps `lastText`. The empty preview reset at a retry no longer replaces it, the results view opens only once text exists, and a failed part keeps `err.partialText||lastText`.
- **M22 — Priority merge.** `paMergeTopics` groups a top-level bullet with its indented lines and drops only a whole repeated item.
- **M23 — page counters.** `N2A_PDF_CHROME`'s counter alternative is `^(?:page\s+)?\d+\s*(?:\/|of)\s*\d+\s*(?:$|date)`; the date, URL and slug alternatives are unchanged.
- **M24 — decimal answers.** The label lookaheads read `\.(?!\d)`; `X2A_LABEL_ONE` likewise. `n2aConvertText` uses `keyed=q.type!=='Calculation'&&q.options.length>0` for label matching and the choice checks.
- **M25 — citations.** `n2aStripSources` strips `(Source: …)` and a trailing `Source: C<n>…`, not any prose "sources:".
- **M26 — choice splitting.** `n2aPdfChoiceLines` takes the first next-label mark that follows sentence punctuation, else the first mark.
- **M27 — ordering digit lists.** `n2aConvertText` warns about and flags an Ordering card whose answer is only a digit list.
- **M28 — count mismatches.** `n2aPdfToWorksheetText` numbers questions 1..n and maps each answer through printed → sequential number. Orphans are numbered after the last question, and the key is written in number order. reviewAll is unchanged.
- **M33 — plain text.** `markdownToPlainText` removes fence marker lines first, then bold and italic only as `(^|[^\w*])\*{1,2}(?=\S)…\S\*{1,2}(?![\w*])`, then inline code.

- **M29 — boot check.** `verify-repo.js` adds `bootSmoke(code, source)`:
  - `new vm.Script` on the react-transformed block and on each plain `<script>` in the page (at least two are required);
  - then `vm.runInNewContext` of the block with inert React/ReactDOM/DOM/storage/library stubs and a 10-second limit.
- **L45 — harness.** `latte-tests.js` `t` passes only `cond === true`, and its async run ends in `.catch(…exit(1))`.
- **M31 — committable exports.** `.gitignore` adds `nclex_questions*.md`, `nclex_questions*.txt`, `*_anki*.txt`, `nclex_images_anki_transcripts*.json`, `latte_anki_import*.txt`, `anki-source-*.json`, `LATTE-Knowledge-Base-recovery-*.txt` and `LATTE-Case-Study*.txt`; no tracked file matches them. A harness assertion extracts every literal download name from the app (at least 12) and adds an example of each computed name. Each one must pass `git check-ignore --no-index`.
- **M32 — golden GUIDs.** The two worksheet and two Extractor GUIDs of the existing fixtures, and one non-ASCII stem's GUID, are pinned. These are the recorded v17.14 values, not yet compared with the Python scripts.
- **M30 — truncation split.** Two behavioural tests drive the shipped build handler with a `truncated` transport error.
- **M1 — Babel preset.** `<script type="text/babel" data-presets="react">`. @babel/standalone 7.23.9 then uses `presets:['react']` plus its default plugins (class properties, object rest spread, flow strip types) with inline source maps; `verify-repo.js` transforms with the same presets and plugins as `BROWSER_BABEL_OPTIONS`, so the boot check runs the code the browser runs. In Node: 10.0 s / 4.81 MB (default) against 1.6 s / 3.88 MB. The two tools that used `['env','react']` to mimic the browser now use `['react']`.
- **M12 — worksheet key split.** `\n[^\S\n]*(?:[^\w\s][^\S\n]*)*FINAL[^\S\n]*(?:[—–-][^\S\n]*)?VERIFY\b|…` (reviewer F's form).
- **L17 — Extractor numbering.** The five `(?:^|\n)\s*` prefixes in `nclexSplitByQNum` are `(?:^|\n)[^\S\n]*`. Positions now point at the last newline before a marker; slices are trimmed, so items are identical.
- **L40 — case numbers.** The range loop matches a sticky copy of `CASE_CLINICAL_TOKEN_RE` at the upper endpoint instead of collecting every later token.
- **Equivalence.** 120,000 random inputs (case fields, extractor text, PART 4 keys) give identical results before and after.
- **M18 — Anki.** `lintAnkiCard` caches by note object and checks text, extra, tags, pipeCount, parse-issue count and tag contract; it returns a copy. `ankiReviewCandidates` caches each note's rows by object and checks text and id. On a synthetic deck: 1,000 notes 67 → 33 ms per edit, 2,000 notes 136 → 62 ms; lint calls per edit 7,000 → 1. NCLEX to Anki builds `previews` (sanitized front and back) in a `useMemo` on `shown`.
- **L27 — PDF text.** `pdfWalkPages` hands `onPage` its text content as a fifth argument.

## Verification

- `node verify-repo.js`: all gates pass.
  - 3,753 assertions (111 new: 9 for step 6, 7 for step 7, 5 for step 8, 7 for step 9, 83 for step 10); all eleven frozen prompt hashes unchanged.
  - The new V8 compile and top-level boot check passes.
  - Prompts.md regenerated for the new filename, plus the case builder's new narrative rule.
  - LF and version checks; full JSX Babel transform.
- Every step 6 and 7 assertion fails on the bytes before its step.
- Step 8:
  - The boot check fails on a copy with `/[z-a]/` (SyntaxError) and on one with a read-before-declaration (ReferenceError).
  - The harness exits 1 for a broken test anchor under `--unhandled-rejections=warn`.
  - The export-name assertion fails against the previous `.gitignore` and lists the exposed names.
- Step 10: every new assertion fails on the step 9 snapshot. Each group also confirmed its patch on a fresh copy with the full verifier. Existing assertions changed with the code:
  - 'REPAIRED is a distinct status';
  - 'choices are rendered as a list under the stem';
  - the R04 `processJob` anchor.
- Step 9: five of its seven assertions fail on the step 8 bytes; the two cache checks pass on both, by design. Three source pins changed with the code (the shared page walk, the NCLEX to Anki PDF reader and its sanitized preview).
- Of the other earlier claims: Reviewer E's reproductions for M23–M28 and M33 now give the expected output.
- Changed assertion: the v17.12 test no longer expects a "Why B is incorrect" item to stay unshuffled. A new assertion requires such an item to validate and shuffle with each rationale on its choice.
- Version literals read 18.0.
