# Nursing Study Suite v21.2 — Release Verification Record

Date: 2026-11-13
Canonical file: `Nursing-Study-Suite v21.2.html`

## Scope Summary

1. **Multi-Select Source Role Checkboxes & Mixed-Lens Layer Routing (`kbNormalizeSourceRoles`, `kbToggleSourceRole`, `kbBuildFocusBlock`, `kbCoercePlateFields`, `mergeLatteParts`, `KnowledgeBaseBuilder`)**
   - Replaces the single-select Step 01 `<select>` role dropdown with multi-select checkboxes on both the default **Source roles** reference box and every uploaded PDF, PPTX, and flashcard photo chip, allowing any combination of `RN Core`, `Patho Bridge`, `Exam / Diff Bridge`, and `Pharm / GDMT Bridge` in a single build.
   - Preserves 100% byte-identical prompt headers when a single role is selected, and emits `SOURCE ROLES FOR THIS CHUNK (MULTI-SELECT)` + `MULTI-ROLE LAYER RULE` when multiple roles are selected.
   - Keeps untagged bedside/safety facts in **RN Core** when `RN Core` is co-selected alongside Bridge role(s) (while filing model-tagged `clinicalLayer: 'bridge'` facts under collapsible **NP Bridge** sections), and defaults untagged non-safety facts to `clinicalLayer: 'bridge'` only when pure-Bridge role(s) are selected.

2. **Inline Source Role Breakdown (`KB_SOURCE_ROLE_GUIDE`, `KnowledgeBaseBuilder`)**
   - Displays plain-English reference descriptions right beside each Step 01 checkbox (and on per-file checkbox `title` tooltips) mapping **RN Core** (*Saunders, Ignatavicius, lecture slides, drug cards*), **Patho Bridge** (*Porth, McCance*), **Exam / Diff Bridge** (*Jarvis, Bates*), and **Pharm / GDMT Bridge** (*Lehne, guidelines*), plus a 1-click **`Apply to all N files`** reset button when per-file role overrides differ from the default selection.

3. **Full Priority Analyzer Alignment Across Priority, NCLEX Generate, and Case Studies (`PRIORITY_ORDER_RULES`, `paBuildExtractPrompt`, `paBuildSynthPrompt`, `NCLEX_PLATE_TRAP_RULES`, `CASE_SLOPE_SYNC_RULES`)**
   - Carries `B1` Organ Hierarchy (`brain > lung > heart > liver > kidney > pancreas` applied to the finding/qualifier's organ) and `LOC vs. AIRWAY` special precedence from `PriorityAnalyzer` into `PRIORITY_ORDER_RULES`.
   - Adds deceptive "pseudo-improvement" (e.g., *silent chest*, *abrupt perforation pain relief*) under `UNSTABLE` across Stage 1 Harvest, Stage 2 `R5`, and `PRIORITY_ORDER_RULES`.
   - Explicitly subordinates `NCLEX_PLATE_TRAP_RULES` and `CASE_SLOPE_SYNC_RULES` to `PRIORITY_ORDER_RULES` so `R1`/`R2` crisis rescue prescriptions and `R8` gating assessments are never overridden by "hands-first" shortcuts.

4. **NGN `Q1 → Q6` Study View Sub-Section Order (`renderKBMarkdown`)**
   - Orders `Treat` as **`1. Priority Bedside & Safe-Administration Actions`** followed by **`2. Pharmacology, Hold Rules & Provider Orders`**, and `Educate` as **`1. Evaluate — Expected vs. Worsening Trends`** followed by **`2. Educate — Discharge & Self-Management`**, matching the chronological inpatient-to-discharge sequence.
