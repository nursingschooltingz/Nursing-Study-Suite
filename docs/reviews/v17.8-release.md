# v17.8 release verification

Date: 2026-09-30. Release: v17.8. Prepared from the v17.7 tree at commit `647f8f1`.

## Why

The user ran a 70-question NCLEX Generator worksheet (67 produced) that failed validation with 16 errors and 19 warnings. Fifteen errors came from the one ordering item in each batch: 6 of the 7 ordering answers were written in shapes the checks could not read. Because every batch had at least one error, the item-quality audit ran on none of them. The sixteenth error (batch 3 Q9: correct-answer reasoning cites only supporting context) is a legitimate grounding finding.

The ordering answer key entries in the exported worksheet used these shapes:

- `ANSWER:` with nothing after it, over `1: Inspection` lines (Q3), over `___ 3` blanks filled with positions (Q19), or over a numbered list (Q62).
- `ANSWER: Inspection, Auscultation, Percussion, Palpation` (Q41).
- `7. ORDER: 4, 1, 5, 2, 3` and `10. ORDER: 4, 2, 1, 3` with no ANSWER header (Q37, Q60). These entries were lost, which produced the count and numbering errors in batches 4 and 6.
- `ANSWER: 2, 4, 1, 3` (Q27, accepted).

A bare digit list meant the sequence of step numbers on Q27 but each step's position on Q37 and Q60. Each entry's own explanation lines confirm which.

## Change

`ngCanonicalOrderingAnswers` runs on each batch after `ngLetterNumberedOptions` and before splitting or checking. For each ordering item, it reads the order from the entry itself:

- step texts in order on the ANSWER line,
- step and explanation lines (every listing must agree),
- or blanks filled with positions.

When the order is found, the ANSWER line is restated as the step texts joined by arrows, and any source reference on the original line is kept. A digit list is accepted only when those lines confirm one of its two meanings; contradictory digits are left as written. An ordering entry labelled ORDER or SEQUENCE gets its ANSWER header even when its order cannot be confirmed, so it is no longer lost and is still flagged. The prompts, the frozen hashes and the warning tiers are unchanged.
