# v20.2 release verification

Date: 2026-11-12. Release: v20.2. Prepared from the v20.1 tree at commit `d522280`.

## Why

`gemini-3.8-flash` is scheduled for shutdown on August 18, 2026, and is succeeded in the Gemini 4 family by `gemini-4-hydrogen` (supporting `low`, `medium`, `high`, and `xhigh` thinking levels). v20.2 moves the suite's fast-tier default to `gemini-4-hydrogen`, adds `xhigh` thinking across **Study settings** and inline tool controls, auto-upgrades retired Flash defaults stored in existing browser `localStorage`, and enforces Gemini 4 transport guards.

## Change

- **Default fast-slot upgrade & saved-storage auto-migration (`MODEL_SETTINGS_DEFAULTS`, `LEGACY_FLASH_DEFAULTS`, `loadModelSettings`):**
  - Upgrades `MODEL_SETTINGS_DEFAULTS.flashModel` from `'gemini-3.8-flash'` to `'gemini-4-hydrogen'`.
  - Auto-migrates saved retired default Flash IDs (`'gemini-3.8-flash'`, `'gemini-3.7-flash'`, `'gemini-3.6-flash'`, `'gemini-3.5-flash'`) in `localStorage` (`latte_model_settings_v1`) to `'gemini-4-hydrogen'` on reload while preserving any custom user-typed model ID.
- **`xhigh` thinking level & Argon compatibility guards (`THINKING_LEVELS`, `ConfigSidebar`, `AnkiGenerator`, `NCLEXToAnki`, `tools/repo-checks.js`):**
  - Expands `THINKING_LEVELS` to `Object.freeze(['low','medium','high','xhigh'])`.
  - Updates **Study settings** (`ConfigSidebar`) labels from **Flash** to **Hydrogen**, adds `xhigh` pills to all per-tool Auto profile rows and Manual mode (enabled on Hydrogen, disabled on Argon with an explanatory tooltip, and clamped to `high` when switching a row to Argon), adds a one-click **Reset defaults** action beside **Model IDs**, and adds `xhigh` to the **Anki Source Checker** and **NCLEX → Anki** thinking selectors and CLI `--level` validation.
- **Gemini 4 transport guards (`geminiIsHydrogen`, `geminiGenerationConfig`, `geminiRequest`):**
  - Requires an explicit `thinkingLevel` on Hydrogen requests as well as Argon requests so an omitted level cannot silently fall back to Hydrogen's `high` built-in default.
  - Refuses `xhigh` on Argon before any network call (`'Argon does not support thinking level xhigh; choose low, medium or high.'`).
  - Increases default HTTP client watchdog timeout (`timeoutMs`) from `600,000 ms` (10 min) to `900,000 ms` (15 min) per Google's Gemini 4 migration checklist.
- **Unchanged:**
  - All 11 frozen prompt constants and `prompt-baseline.json` are byte-identical.
