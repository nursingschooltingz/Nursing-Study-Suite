# v20.3 release verification

Date: 2026-11-12. Release: v20.3. Prepared from the v20.2 tree at commit `299dec6`.

## Why

v20.3 completes the cutover of all fast-slot state keys, Auto profile rows, inline tool selectors, and CLI measurement baselines to `gemini-4-hydrogen` (`hydrogenModel`, `hydrogenLevel`, `m: 'hydrogen'`) and lands Phases 1–10 of the production-readiness code review remediation across model-settings schema versioning, IndexedDB/recovery resilience, standalone KB entity deduplication, Case Packet lifecycle/registry consistency, binary/archive intake bounds, Gemini secret redaction/SSE keep-alives/prefix caching, DOMPurify/print/PDF.js security hardening, native plain `<script>` utility splitting + lazy tab mounting, NCLEX persisted-Point inheritance + bloated-exemplar concept auditing, and $O(1)$ accumulation/reconciliation.

## Change

- **Complete Hydrogen model slot, `schemaVersion: 2` persistence, and multi-tab sync (`MODEL_SETTINGS_DEFAULTS`, `MODEL_SETTINGS_SCHEMA_VERSION`, `TOOL_PROFILE_DEFAULTS`, `loadModelSettings`, `saveModelSettings`, `App`):**
  - Moves the fast-slot state/profile keys to `hydrogenModel: 'gemini-4-hydrogen'`, `hydrogenLevel: 'low'`, and `m: 'hydrogen'` across all seven fast-slot Auto profile rows (`knowledge`, `knowledgeAudit`, `cardTranscribe`, `priorityHarvest`, `anki`, `nclex`, `gizmo`), **Study settings** (`#suite-hydrogen-model`), **Anki Source Checker** (`<option value="hydrogen">`), **NCLEX → Anki** (`cfg.hydrogenModel`), and CLI measurement tools.
  - Persists `schemaVersion: 2` via `saveModelSettings` so legacy storage migration runs only on pre-v2 payloads (never overwriting explicit custom model IDs on reload), clamps `xhigh -> high` on non-Hydrogen custom models while keeping Argon's explicit HTTP 400 refusal, and synchronizes settings and Auto profiles across open tabs via `window.addEventListener('storage', ...)`.
- **Storage resilience, standalone entity integrity, Case Packet lifecycle, and intake bounds (Phases 1–5):**
  - Hardens `kbOpenDB(timeoutMs = 4000)` (`onblocked`, `db.onversionchange`, watchdog timeout, late-handle close) and `kbArchiveRecovery` (pre-write pruning, full archive eviction retry on quota overflow, automatic `.json` download fallback).
  - Enforces `KB_FACT_BUCKETS` on explicit standalone entity `facts[]` (`kbCoerceEntityBucket`) and deduplicates same-slug `medications`, `diagnostics`, and `scoringTools` across chunks and imports (`kbDedupEntities`) with contiguous `fact-N` numbering.
  - Memoizes `artifactSourceSnapshot` via `WeakMap`, commits completed Case Packet entries deterministically inside `CaseStudyGenerator.run`, and prunes removed/cleared Case Packet entries from `artifactRegistry.caseStudies` (`App.pruneArtifact`).
  - Enforces `150 MB` PDF, `25 MB` image / `15 MB` unresized inline / `64 MP` header-probed image dimension, and `50 MB` transcript JSON bounds; releases PDF.js workers (`destroyPdfDoc`) and zeroes canvas buffers; pre-checks PPTX ZIP EOCD entry counts, rejects XML `<!DOCTYPE`/`<!ENTITY`, guards `zip.files` with `hasOwnProperty`, and hardens map accumulators with `Object.create(null)` + `Object.hasOwn`.
- **Transport security/caching, sanitizer & print isolation, startup split, domain alignment, and $O(1)$ indexing (Phases 6–10):**
  - Adds `redactApiSecrets` error/`onMeta` scrubbing (preserving strict-mode `AbortError` `DOMException` instances), uniform `0..999 ms` network/timeout retry jitter (plus CLI retry jitter in `neia-retest.js` and `davis-transcribe-test.js`), `stream: true` SSE keep-alive streaming on KB Pass 1/Pass 2 and `nclexCallGemini` (with JSON mock fallback), `systemInstruction` / static-first `parts[0]` prefix caching across KB extraction/verification, card OCR, NCLEX extraction/generation, and image-to-Anki transcription, and password-manager ignore attributes + **Clear** on `#suite-api-key`.
  - Installs `ensureDomPurifyHooks` (`n2aSanitizeStyle` typography property allowlist), freezes `N2A_CARD_POLICY` (`ALLOW_DATA_ATTR: false, ALLOW_ARIA_ATTR: false`), restricts `mdToSafeHtml` `a[href]` to `https?://` or `#`, forces `isEvalSupported: false` via `pdfSafeDocParams`, clears child `about:blank` `sessionStorage` and attaches opener `#lp-print` click handling in `exportAsPdf`, and extends `printViaIframe` fallback removal to `180,000 ms`.
  - Splits ~1,080 lines of non-JSX ES2020 utilities into a native `<script>` block ahead of `<script type="text/babel" data-presets="react">` and lazily mounts unvisited tabs on first visit (`visitedTabs` / `NoopTool`).
  - Inherits persisted `numberedPoints` in `NCLEXGenerator` (`buildFocusBlock` and `ngFocusPlan` `_inheritPersistedPoints`) and routes overflow picks across `_batchCaps`, adds warn-only `bloatedExemplars` to `auditKbConcepts`, clamps `#priority-chunk-size` to `60,000`, indexes `nclexAccumulate` in $O(1)$ via `WeakMap`, deduplicates `kbReconcileStored` in one `JSON.stringify` per candidate, holds `downloadBlob` object URLs for `60,000 ms`, and batches `git check-ignore --stdin` in `latte-tests.js`.
- **Unchanged:**
  - All 11 frozen prompt constants and `prompt-baseline.json` are byte-identical.
