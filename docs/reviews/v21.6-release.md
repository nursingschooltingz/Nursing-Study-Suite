# Nursing Study Suite v21.6 — Release Verification Record

Date: 2026-11-16

## Scope Summary (Ordered Implementation Plan Steps 1–9)

1. **Step 1 — PDF CLI Decompression-Bomb & >512 MB Crash Hardening + Helper Deduplication (`tools/pdf-toc-slice.js`)**
   - Caps `zlib.inflateSync` / `zlib.inflateRawSync` metadata stream output at `MAX_PDF_META_STREAM_BYTES` (`32 MB`).
   - Validates `/DecodeParms` predictor `Columns` (`<= 65,536`), `Colors` (`<= 16`), `BitsPerComponent` (`<= 16`), and row width before allocating buffers.
   - Scans >512 MB PDFs in `8 MB` windows with `64 B` seam overlap (`fallbackScanObjects`) so large textbooks never trigger V8 `ERR_STRING_TOO_LONG`.
   - Extracts shared TOC/page-range helpers directly from canonical HTML (`loadSuiteTocHelpers()`), eliminating ~260 lines of duplicate parser logic.

2. **Step 2 — Default `store: false` Privacy Opt-Out (`geminiRequest`, `neia-retest.js`, `davis-transcribe-test.js`, `ConfigSidebar`)**
   - Defaults `body.store = false` on top-level `GenerateContentRequest` bodies without mutating caller inputs, opting out of 55-day server-side prompt retention on paid Gemini API projects.
   - Automatically falls back once without `store` (consuming zero caller retries and caching `_storeUnsupported` for the session) if an older or free-tier endpoint returns HTTP `400` rejecting `"store"`.
   - Documents paid vs. free-tier data-retention behavior in `#suite-api-help`.

3. **Step 3 — ISO-BMFF (`HEIC`/`HEIF`/`AVIF`) Image Bomb Probing & Single-Read `NCLEXToAnki` Intake (`probeImageDimensions`, `cardValidateImageSafety`, `i2aFileKey`, `i2aImagePayload`)**
   - Parses ISO-BMFF `ftyp` + `ispe` `FullBox` headers (taking maximum frame area across all `ispe` boxes so thumbnail boxes never mask a >64 MP primary image bomb) and widens `cardValidateImageSafety`'s header slice from `64 KB` to `512 KB`.
   - Skips `file.arrayBuffer()` on >25 MB files in `i2aFileKey` and caches `<=14 MB` buffers in `i2aFileKey._bufs` (`WeakMap`) so `i2aImagePayload` reads screenshots once instead of three times.

4. **Step 4 — `extractJSON` Fence/Stack/Inline Hardening & Step 01 Manual PDF Slice Bounds Validation (`extractJSON`, `KnowledgeBaseBuilder.build`)**
   - Tries all fenced blocks first (prioritizing ```` ```json ```` over untagged prose fences), tracks nested `{`/`[` delimiters on an explicit stack, and recovers inline JSON after `[P1]` prose brackets while still rejecting malformed outer JSON envelopes.
   - Validates manual Step 01 PDF page slices against `getPdfDoc(f).numPages`, reporting actual page counts on out-of-bounds slices and warning when clamping partial overflows.

5. **Step 5 — Sub-500 KB `<script type="text/babel">` Split (`Nursing-Study-Suite v21.6.html`, `verify-repo.js`)**
   - Moves ~966 KB of pure non-JSX ES2020 domain modules, validators, and async batch runners into the native plain `<script>` block ahead of `<script type="text/babel" data-presets="react">`, shrinking `<script type="text/babel">` from `1.46 MB` to `~490 KB` (`< 500,000` chars enforced by `verify-repo.js`) and eliminating Babel's 500 KB code-generator deoptimization.

6. **Step 6 — Gemini Transport, Safety, Prefix Caching, & Standard JSON Schema (`geminiRequest`, `SAFETY_SETTINGS`, `caseSplitSystemPrompt`, `buildKbFactItemSchema`, `GizmoImporter`, `NCLEXToAnki`, `NCLEXGenerator`, `CaseStudyGenerator`, `cardTranscribe`)**
   - Adds `HARM_CATEGORY_CIVIC_INTEGRITY` (`BLOCK_NONE`) across `SAFETY_SETTINGS` and `MEASUREMENT_SAFETY_SETTINGS`.
   - Routes `Content-Type: application/json` replies through `resp.json()` under `stream: true` and tightens inter-frame SSE idle timeout to `180s` (`Math.min(timeoutMs, 180000)`) after streaming starts while preserving the `900s` initial response budget.
   - Hoists static `GIZMO_CONVERT_PROMPT` (`+ stream: true`), `I2A_TRANSCRIBE_PROMPT` / `I2A_ANSWER_PROMPT`, and static `CaseStudyGenerator` rules (`caseSplitSystemPrompt`) into `systemInstruction`, attaches standard lowercase `responseJsonSchema` across structured JSON endpoints, and modernizes `buildKbFactItemSchema` to standard JSON Schema.

7. **Step 7 — CSP `script-src`, DOM Sanitizer Fallback Without `document.write`, Secret Scrubbing, & CLI Hardening (`Nursing-Study-Suite v21.6.html`, `tools/repo-checks.js`, `neia-retest.js`, `davis-transcribe-test.js`)**

   - Replaces cross-origin `document.write` DOMPurify fallback with `<template id="dompurify-fallback">` + DOM loader, `_renderSanitizerHaltBanner`, and React mount gate.
   - Unifies `>=8`-char and URI-encoded key scrubbing across `redactApiSecrets` and `redactSecrets` (including `NCLEXGenerator` and `CaseStudyGenerator` audit errors), and adds `AbortSignal.timeout(900000)`, `cliRetryDelayMs` (`RetryInfo` + `Retry-After`), and `0o600` report permissions to CLI tools.

8. **Step 8 — IndexedDB Fast-Path CAS, `WeakMap` Caches, Live `NCLEXToAnki` Reactivity, & 2-Lane Split Concurrency (`kbLoadPersisted`, `kbSavePersisted`, `kbRunLanes`, `kbProjectExamTraps`, `ngAllocateBatch`, `selectCaseFacts`, `kbMatchTocNodes`, `NCLEXToAnki`)**
