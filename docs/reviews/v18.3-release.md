# v18.3 release verification

Date: 2026-10-14. Release: v18.3. Prepared from the v18.2 tree at commit `1a76dc7`.

## Why

The user asked for the NCLEX to Anki image option to convert to a PDF, not just to Anki cards. Questions read from images could only be written as an Anki import file.

## Change

- `i2aWorksheetMd(questions)` returns `{md, count}`: a worksheet in the NCLEX Extractor's layout. Questions and choices come first; the answer key follows a `pagebreak` marker. Each key entry has the answer, the choices marked ✓/✗ with their rationales, the rationale, any extras (strategy, tip), AI labels and the source images. The marks and labels match `i2aRenderBack`.
- Questions are dropped as for cards when the stem is empty or the GUID repeats. A question with no answer is kept, and its key entry says so.
- `i2aMdEsc` escapes transcribed text: Markdown punctuation, line-start `#`, `>`, `+`, `=`, `-` and "1." list markers. Line breaks become hard breaks.
- `i2aConvert` sets `result.worksheet`. The results header shows **🖨 PDF** in image mode and calls the shared `exportAsPdf`, which sanitizes through `mdToSafeHtml`.
- When a run writes no cards but read questions, the banner says the questions can still be printed.
- The visible version is 18.3. No prompt changed and no Gemini call was added.

## Verification

- `node verify-repo.js`: all gates pass, 3,769 assertions (5 new).
  - New: the worksheet order and page break; the key's marks, rationale and sources; Markdown escaping, an unanswered question and an empty stem; a run with no cards still has a worksheet; the button calls `exportAsPdf(result.worksheet.md, …)`.
  - Updated: version literals read 18.3.
- **Prompt bytes.** The 11 frozen prompt hashes match; `prompt-baseline.json` is unchanged. `Prompts.md` was regenerated for v18.3.
- **SRI.** The eight SRI-pinned scripts and both PDF worker copies were re-hashed and match.
- **Browser.** The app was served alone on loopback, and a synthetic three-question worksheet was rendered with `buildPrintDoc`. The page text showed the questions, a key with ✓/✗ rationales, an escaped `*`, and the unanswered-question line.
