# v20.0 release verification

Date: 2026-11-12. Release: v20.0. Prepared from the v19.1 tree at commit `06bfdbe`.

## Why

v20.0 delivers four major study-workflow expansions requested since v19.1:
1. **Concept-based curriculum (`LATTE + P`)** support across Knowledge Base extraction, Study View, Anki flashcards, Priority, NCLEX generation, and Case Studies for Giddens-style concept-and-exemplar nursing programs.
2. **HESI/ATI/NGN Exam Trap Blocks (`LATTE + P + Traps` Phase 1)** mapping clinical tie-breakers, dynamic slopes, bedside-vs-ordered action splits, hold triangles, and never-click guardrails into Study View and active-recall generators.
3. **Unified Giddens Concept + Condition multi-select scope & mixing** across NCLEX Question Generator and Clinical Case Study Generator (with `Argon · high` default profile for NCLEX generation).
4. **08 · Import to Gizmo**, an AI-driven chunked Anki-to-Gizmo.ai flashcard converter replacing the standalone Python `Gizmo Converter` script.

## Change

- **Concept-based curriculum (`LATTE + P`):**
  - `kbBuildFocusBlock` appends `KB_CONCEPT_CURRICULUM_RULES` when Step 01's Overarching concept(s) or Auto-detect toggle is active without activating Focus `SCOPE` / `PRIORITIZE` modes.
  - Additive optional schema fields (`entryRole`, `concept`, `relatedConcepts`, `conceptScope`, `metadata.concepts`, `metadata.conceptAuto`, zero extra keys when inactive), cross-chunk qualifier canonicalization (`kbCanonConceptKey`), sibling duplicate hoist onto parent Concept Overviews (`mergeLatteParts`), entity concept inference (`kbInferEntityConcept`), warn-only Step 6 `auditKbConcepts`, cited `BriefPatho` Concept Bridge & Priority Differentiator Study View rendering, `Concept::`/`Scope::` Anki tags (`ankiStampConceptTags`), and `ngConceptCoverage` blueprint reporting.
- **Exam Trap Blocks & Active-Recall Trap Pipeline (`LATTE + P + Traps`):**
  - Default-on Step 01 `Map HESI/ATI Exam Traps` toggle (`KB_EXAM_TRAP_RULES`), 10 `trapRole` values, `contrastWith`, and `contrastPartners` (zero extra JSON keys when empty).
  - Study View `kbProjectExamTraps` (5 cited trap bullets + 2-column Twin-Diagnosis Contrast Strip + optional legacy empty worksheet toggle), warn-only Step 6 `auditKbExamTraps`, `Trap::<Kind>` Anki tags (`ankiStampTrapTags`), `Exam Traps only` Anki scope & review filter pills, and `TRAP_ROLE_WEIGHT = 1` ordering across Anki, Priority, NCLEX, and Case Studies.
- **Unified Giddens Concept + Condition Scope Mixing & Auto Profile:**
  - Shared `kbResolveScopeGroups` and `kbCollectScopeCatalog` across `NCLEXGenerator` and `CaseStudyGenerator` supporting any simultaneous union of Giddens Concepts and specific Conditions/meds/labs while keeping single-entry packets byte-identical.
  - Round-robin multi-entry case fact sampling (`selectCaseFactsMulti`), per-fact `ENTRY:` attribution, `Comorbid / Evolving Trajectory` vs. `Differential / Twin Tie-Breaker` framing, `allowedConditionNames` validation, and `TOOL_PROFILE_DEFAULTS.nclexgen` updated to `Argon · high`.
- **08 · Import to Gizmo (`GizmoImporter`, `GIZMO_CONVERT_PROMPT`, `AnkiDeckCtx`):**
  - Eighth rail tool (`Flash · low` in Auto profile) reading live kept notes from **03 · Anki** or uploaded/pasted `.txt`/`.tsv`/`.csv` Anki exports (UTF-8/UTF-16 BOM, multi-line CSV-quoted `#html:true` rows, v19 `Concept::`/`Scope::`/`Trap::` tags, cloze `::hints`, and 4-column `NCLEX to Anki` exports).
  - Editable, `localStorage`-saveable Gizmo Import Instructions box (`loadGizmoImportPrompt` / `saveGizmoImportPrompt`) with `Copy`, `Save`, and `Reset default`.
  - Chunked AI formatting reconciled card-by-card against `gizmoDeterministicCard` (`gizmoReconcileChunk`) so empty `Extra` backs remain strictly `""`, all `{{cN::...}}` clozes stay on one card as `[blanks]`, non-cloze `[brackets]` become `(parentheses)`, `&lt;`/`&gt;` comparators survive HTML stripping, and zero cards or numbers are dropped or altered.
  - Virtual textbook PDF pagination (`gizmoPaginateCards`, ~18 cards / ~2,500 chars per page) with **Chunk slideshow** (default 5 PDF pages' worth per chunk), **Copy all** (`*_gizmo.txt`), and **Page range** copy modes.
- **Unchanged:**
  - All 11 frozen prompt constants and `prompt-baseline.json` are byte-identical.
