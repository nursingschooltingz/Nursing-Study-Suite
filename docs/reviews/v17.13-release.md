# v17.13 release verification

Date: 2026-10-13. Release: v17.13. Prepared from the v17.12 tree at commit `f988e52`.

## Why

The user asked to turn the Pro mode into Argon mode and rename every Pro reference. Argon's API guidelines name three things a bare model-ID swap would break or quietly change:

1. **Output ceiling.** Every request asked for `maxOutputTokens: 65536`. Argon allows 32,768 thinking-plus-output tokens on a non-streaming request; a browser `fetch` to `generateContent` is that case. Thinking counts against the same budget, so a `MAX_TOKENS` stop on a JSON request means truncated JSON.
2. **Thinking parameters.** A `thinkingBudget` or the MINIMAL level returns HTTP 400. The suite already sent only low, medium or high, but nothing enforced it.
3. **Default reasoning.** 3.1 Pro defaulted to high and Argon defaults to medium. A request without a level would get less reasoning with no error.

## Change

- **Rename.**
  - `MODEL_SETTINGS_DEFAULTS` is now `{flashModel, argonModel:'gemini-4-argon', thinkingMode, flashLevel, argonLevel:'high'}`.
  - App state, `cfg`, `forTool` (family `'argon'`), the settings drawer (toggle, Thinking Level label, per-tool buttons, the `suite-argon-model` field), the Anki source checker option and the `.model-dot.argon` style use Argon.
  - Comments that record measurements made on 3.1 Pro keep that fact.
- **Migration.**
  - `loadModelSettings` carries a saved `proLevel` into `argonLevel` unless an `argonLevel` was saved. A saved `proModel` is ignored.
  - The profile loader maps a row saved as `m:'pro'` to `'argon'`, next to the existing `casesAudit` shim.
- **Transport.**
  - `geminiOutputCap(model)` returns 32,768 for any ID matching `/argon/i` and 65,536 otherwise.
  - `geminiGenerationConfig` copies the caller's config. It clamps `maxOutputTokens` to that cap and refuses three cases as a fatal HTTP-400-shaped error before any fetch: a `thinkingBudget`, a level outside `THINKING_LEVELS`, or an Argon request with no level.
  - `callGemini` and the four direct `geminiRequest` callers no longer set a ceiling.
  - Every metadata report carries `maxOutputTokens`.
- **Truncated JSON.**
  - A `responseMimeType: application/json` request that stops with `MAX_TOKENS` throws `{truncated, isFatal, finishReason, partialText}`. It has no HTTP status, so `geminiHaltsBatch` treats it as a per-chunk failure.
  - Knowledge Base extraction's split-and-requeue moved into its `catch`, keyed on `e.truncated`. The audit pass keeps a truncated reply's partial text as `auditResponse`; the audit still counts as failed.
  - Case generation routes the error to the existing invalid-response panel with the partial text.
  - Plain-text callers are unchanged.
- **Displayed ceiling.** `TruncationNotice` and the Anki, NCLEX Generator and case log lines print `meta.maxOutputTokens` instead of a literal 65,536.
- **Priority.**
  - `paSynthPartChars(model)` scales `PA_SYNTH_PART_CHARS` by the model's ceiling: 40,000 on Flash and 20,000 on Argon.
  - Synthesis resolves its model before grouping and passes that limit to `paSynthGroups`.
- **Measurement tools.**
  - `tools/repo-checks.js` gains `measurementOutputCap`, which `measurementPlan`, `neia-retest.js` and `davis-transcribe-test.js` use.
  - The NEIA default is `gemini-4-argon` at high, and NEIA refuses `--level minimal` on Argon.
  - `--app-profile` resolves `(flash|argon)` rows.

## Verification

- `node verify-repo.js`: all gates pass.
  - 3,593 assertions (23 new).
  - All eleven frozen prompt hashes unchanged.
  - `Prompts.md` regenerated for the new filename only.
  - LF and version checks pass, and the full JSX Babel transform succeeds.
- **New assertions:**
  - `tools/transport-regression-tests.js` (14):
    - the cap by model ID;
    - an Argon body sent with 32,768 when 65,536 was asked;
    - an unmutated caller body;
    - a Flash default of 65,536;
    - a JSON truncation that is fatal, not retried and per-chunk;
    - an Argon truncation that names 32,768;
    - each refused thinking setting, with zero fetches, the no-level Argon refusal halting a batch;
    - no call-site ceiling literal;
    - the Knowledge Base split, Knowledge Base audit evidence and case panel source contracts.
  - `tools/settings-persistence-tests.js` (4): Pro-to-Argon settings migration, Argon level precedence, Pro profile rows, and the Argon UI labels.
  - `tools/production-priority-tests.js` (2): part sizes by model, and the limit a run actually passes to `paSynthGroups`.
  - `tools/remediation-tooling-tests.js` (3): NEIA refuses `--level minimal` on Argon, the measurement ceiling per model, and Argon profile resolution.
- **Updated assertions:** the existing Pro assertions in the settings, focus, Anki review-quality, lifecycle and provenance tests now name Argon. The version assertions were bumped to 17.13. The standalone Playwright fixtures were renamed to match; Playwright is not installed here, so they were not run.
- **Browser.** The built-in browser pane loaded a scratch copy, served by a local static server, with no API key.
  - Saved v17.12 settings `{proModel:'gemini-3.1-pro-preview', proLevel:'medium', thinkingMode:true}` and a Cases row `{m:'pro'}` loaded as Argon at medium. The drawer showed 🧠 Argon, "Thinking Level · Argon", the orange Argon dot and the "Argon model" field set to `gemini-4-argon`.
  - Storage was rewritten without the Pro keys. The Cases profile button read "Argon".
  - With no saved settings, the default was `gemini-4-argon` at high.
  - The console showed only the existing Babel size note.
- **SRI.** All eight SRI-pinned scripts and both PDF worker copies (cdnjs and jsDelivr) were re-hashed on 2026-10-13 and match their sha384 pins.

## Not measured

- No live Gemini request was made, so the `gemini-4-argon` ID has not been confirmed on a real key. The ID comes from Google's Cloud developer guide; one launch report said it was not yet in the public Gemini API catalog. If a key rejects it, the Argon model field takes the correct ID with no code change.
- The 20,000-character Priority part size on Argon is scaled from the v17.7 Flash run, not measured on Argon.
